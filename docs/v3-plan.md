# v3 固件交付计划与验收约束

本轮按用户确认的产品与架构方案交付，仅修改固件及其开发、验证工具。上位机 SDK 和服务端暂不适配。版本为 `0.3.0-dev`，协议版本 3，直接拒绝 v2。当前单板为合宙 CORE ESP32-C3 简约版、外置 4MB Flash、原生 USB；不扩大到其他板型。

## 产品选择

用户需要无需反复编写固件即可完成总线实验、信号采集和无人值守节点。采用 bus/signal/iot 三种镜像，共享资源、作业、缓存、流程和传输契约。按芯片、板卡、镜像、运行时四层区分能力；不以 API 名字代替实际实现。不提供任意寄存器写入或通用脚本解释器。

所有镜像提供 GPIO、6 路 PWM/4 个共享定时器、ADC1 单次/周期采集、本地任务、温度、USB/BLE、Wi-Fi/WebSocket、存储、流程、诊断、OTA；bus 增加 UART、I²C/SPI 主从、TWAI、RMT；signal 增加连续 ADC、I²S、RMT、Sigma-Delta 和辅助 I²C 主机；iot 增加 UART、I²C/SPI 主机、TWAI、RMT、MQTT、ESP-NOW、低功耗。未编入能力返回 feature_unavailable。

数字信号经 GPIO Matrix 路由；ADC 通道物理固定。GPIO0/1/3/4 可以改作数字用途，同一脚不能同时属于模拟和数字资源。开放 0/1/3/4/5/6/7/10/13/20/21；保护绑带、Flash、USB、GPIO11、状态灯12。13带板载LED负载；5不提供不稳定的ADC2。

## 架构与生命周期

单一 actor 拥有会话、控制权、资源图、版本、作业历史。驱动工作任务处理有界阻塞 IO；异步数据由作业或缓存持有，完成带资源实例与实验 epoch，拒绝过期完成。资源先整体预检/预留，驱动失败保留 fault 与占用，不假称硬件事务回滚。父资源有子资源时拒绝关闭，明确 cascade 才清理。

USB、BLE、WebSocket、MQTT 逻辑客户端分别持有会话；一个控制者，开放实验室访问。任何有效会话可走预留入口 outputs.stop：撤销控制、持久禁止流程自启、增加 epoch、取消流程与队列工作、有界停止驱动并保留失败占用，通信继续。局部停止不能撤回已发出的外部命令。

协议使用 UTF-8 JSON+LF，请求1024字节、响应8192字节、深度16。长操作返回 job_id；accepted 不等于完成。严格 Base64 分块读写缓存，显式溢出/丢弃信息。能力及状态分页；查询状态恢复丢失通知。禁止自动重试写事务。

流程使用声明式步骤、变量、条件、有限循环、周期、等待、超时/失败分支，拒绝无等待无限循环；流程持有资源，断线继续。默认手动，逐流程明确自启；异常复位从入口开始，不续发半笔事务。暂停不假称输出已清理，停止负责取消与释放。

## 系统服务

NVS 设置和 LittleFS 文件不得因初始化失败自动清空；临时上传经校验原子替换。凭据仅可写入，不读回或记录。Wi-Fi STA 为正常态，SoftAP 必须显式开启；维护 AP 暂停 MQTT/ESP-NOW。IoT MQTT3.1.1/5支持TLS、QoS、保留、LWT，拒绝保留控制命令、去重重投递。ESP-NOW不把MAC确认当应用确认。

固定4MB分区：前128KiB、双1728KiB OTA槽、512KiB LittleFS。首次通过USB换分区前备份完整Flash。OTA直接写非活动槽，检查芯片/板型/协议/镜像/长度/hash，仅空闲实验可激活；首次启动自检后确认，否则回滚。OTA不修改bootloader/分区表/eFuse。连续采集与大Flash写入互斥；不宣称无限采集或未经测量的低功耗指标。

## 分批实施与证据

|阶段|交付|验收|
|---|---|---|
|M0|契约、三镜像、分区、锁定依赖、构建工具|独立配置、分区和镜像大小检查|
|M1|资源/矩阵、会话、作业、缓存、停止|生产C ASan/UBSan，冲突、过期完成、取消、清理失败|
|M2|bus外设|驱动生命周期、主从互斥、控制器/缓冲约束|
|M3|signal外设|ADC整单元互斥、DMA、采样顺序与溢出|
|M4|持久化、Wi-Fi维护、OTA|原子替换、错误隔离、回滚与拒绝条件|
|M5|IoT、流程、低功耗|去重、保留命令、超时、循环、自启抑制|
|M6|三镜像软件与单板验证|真实镜像/身份/接口/复位/停止证据|

本轮仅当前C3和电脑。不具备外部I²C/SPI从机互通、CAN收发器、音频、双节点ESP-NOW或电流仪器；相关外部互通/精度必须标为未验证。软件测试、驱动创建、内部回环、真实外设互通是不同证据，不互相替代。缺失实现不得标为通过。
