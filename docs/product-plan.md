# 固件v3产品决策

本轮沿用product-discovery、product-positioning、product-strategy、product-prioritization、product-review和architecture-review的标准。用户明确要求补全总线、外设矩阵和离线能力，只做固件，接受v3破坏性升级与三镜像方案。

## 用户任务与价值假设

面向电子实验、原型开发和无人值守节点用户，替代为每次实验重新写固件、串口手工命令与固定功能测试程序。价值是通过可发现的资源契约完成“接器件→选择引脚→发现冲突→执行→观察→停止→恢复”，减少重复烧录。没有访谈或任务时间基线，“节省多少时间”和市场规模仍是假设。

|任务|固件路径|成功判断|
|---|---|---|
|接UART/I²C/SPI器件|能力→矩阵预检→控制器→子设备→作业结果|冲突可解释，超时不重复写，关闭父子资源有确定结果|
|将模拟脚改成数字用途|关闭ADC资源→同GPIO创建数字资源|ADC物理限制与占用不混淆，保护脚始终拒绝|
|采集/发射信号|signal连续ADC/I²S/RMT及有界缓存|知道原始格式、样本归属、丢弃与容量；不误认为无限流|
|断开电脑运行实验|保存定义→手动start/明确autostart|断线继续、重连可查，pause与stop语义清楚|
|采集后睡眠再继续|流程sleep检查点→重新初始化→下一步|正常唤醒续游标，异常复位不重发半笔事务，停止禁止自启|
|升级/维护设备|显式AP、非活动槽OTA、健康确认/回滚|不会因挂载错误擦数据；失败仍能USB恢复|

## 策略与取舍

集中障碍是能力扩张后控制器、引脚、DMA、内存和持久化的冲突不可见。指导策略为：统一资源所有权，公开限制，三用途镜像控制容量，在完成证据后再扩大板型。bus/signal/iot共享契约，配置不交叉污染。上限不是同时运行承诺。

开放实验室模式允许任何有效会话停止，token只做协调；不做远程生产安全认证。GPIO Matrix可灵活路由数字外设，不能移动ADC模拟通道或挪用Flash/USB脚。Sigma-Delta为数字调制，不能称作芯片没有的DAC。CAN需要收发器；PDM RX没有硬件PCM转换。

本轮不改SDK/服务端，不新增板型，不引入任意代码或寄存器写入，不承诺未经测量的波形/电压/电流精度，不为外部互通补买设备。对明确范围内的驱动和协议完成实现，缺夹具项目如实记未验证。

## 优先级与交付

按依赖排序：M0构建/分区/契约→M1所有权/停止/缓存→M2总线→M3采集信号→M4持久化/OTA→M5流程/IoT/低功耗→M6最终回归。不编造RICE分数；资源冲突、取消竞态、OTA失败和数据误擦的风险优先于增加接口名称。冻结范围与阶段门槛见 [v3计划](v3-plan.md)，执行证据见 [v3状态](v3-status.md)。

工程验收形成开发候选。多端真实无线互通、外设电气与精度、真实用户可用性仍须不同夹具和研究。后续产品评审应观察用户能否独立完成上述任务、解释accepted/completed、区分连接与控制权、识别数据丢失，并在错误后可靠停止。记录真实失败与帮助次数，取得基线后再制定量化目标。
